* Generate Synthetic Data

** Person Documents
#+begin_src bash
# Generate 5 people
python main.py person -n 5

# Generate 100 people and save
python main.py person -n 100 > data/people.ndjson
#+end_src

** Social Media Posts
#+begin_src bash
# Generate 10 posts
python main.py socialmediapost -n 10

# Generate 50 posts with custom dataset
python main.py socialmediapost -n 50 -d twitter_archive > posts.ndjson
#+end_src

** Messages
#+begin_src bash
# Generate 20 messages
python main.py message -n 20

# Generate messages with different model
python main.py message -n 50 -m mistral > messages.ndjson
#+end_src

* Pipeline Examples

** Generate and Process
#+begin_src bash
# Generate and count documents
python main.py person -n 100 | wc -l

# Generate and pretty print
python main.py person -n 5 | jq

# Generate and extract specific fields
python main.py socialmediapost -n 10 | jq '.user'

# Generate multiple types and combine
{
  python main.py person -n 50
  python main.py socialmediapost -n 100
  python main.py message -n 200
} > full_dataset.ndjson
#+end_src

** Filter and Transform
#+begin_src bash
# Generate and filter by field
python main.py person -n 100 | jq 'select(.gender == "female")'

# Count by platform
python main.py message -n 100 | jq -r '.platform' | sort | uniq -c
#+end_src
